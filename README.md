# こども支援案内板（仮）

子どもを支える団体への寄付先を、地域や「届けたいもの」から探せる案内板です。
お金も物も預からず、広告・手数料もありません。寄付は各団体の公式窓口へ直接届きます。

## ふだんの運営（やることはタップだけ）

GitHubアプリ（スマホ）に通知が来ます。開いて、ラベルを付けるだけです。

| 通知 | いつ来る | やること |
|---|---|---|
| リンク切れの確認 | 3日続けて開けないとき | 開いて確かめる → 止めるなら「承認」、問題なければ閉じる |
| 募集終了の可能性 | 公式ページに「受付終了」などが出たとき（週1回確認） | 同上 |
| 半年ごとの再確認 | 確認から180日たったとき（月1回） | 受付中なら「承認」、終わっていたら「停止」 |
| 掲載候補 | 自分で候補を登録したとき | 表示を確認して「承認」→ すぐ公開、X投稿の下書きが届く |

承認されると自動でデータが更新され、数分でサイトに反映されます。
ラベルが効くのはリポジトリのオーナー（あなた）だけです。

### 新しい団体を載せる

GitHubアプリで Issues →「New issue」→「掲載候補を追加」を選び、項目を埋めて送信。
数十秒で「掲載したときの表示」がコメントで届くので、よければ「承認」ラベルを付けます。

## 自動でやっていること

- 毎朝：掲載中の全リンクを確認（403・429・503などのアクセス制限はリンク切れとして扱わない。Amazonは特に慎重）
- 毎週月曜：各団体の公式ページを読み、「募集終了」などの言葉が新しく出たら通知（robots.txtを守り、Amazonのページは読まない）
- 毎月1日：確認から半年たった団体を通知
- 公開時：データを検査し、ダミー・未確認・停止中の団体を自動で外す。運営者名とお問い合わせ先が未設定なら公開しない

## ファイル

- `site/` … サイト本体（index.html / style.css / app.js）
- `site/data/organizations.json` … 団体データ
- `site/data/site-config.json` … サイト名・運営者名・お問い合わせ先・フォームURL
- `scripts/` … 検査と自動運用のプログラム（外部パッケージなし）
- `.github/` … 自動実行の設定と、掲載候補フォーム
- `state/` … リンク確認などの記録（自動で更新）

## 手元で確認する

```
node scripts/build.mjs            # データ検査
node scripts/build.mjs --preview  # ダミー入りの確認用 preview/preview.html を作る
```

公開設定の手順は `SETUP.md` を見てください。
